# General Installation

Install scripts run via for `chezmoi`. Installation docs [here](https://www.chezmoi.io/install/)

```
export GITHUB_USERNAME=marmal88
sh -c "$(curl -fsLS get.chezmoi.io)" -- init --apply $GITHUB_USERNAME
```
